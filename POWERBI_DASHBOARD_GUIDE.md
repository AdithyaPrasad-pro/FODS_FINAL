## 1. Power BI Architecture & Data Model (Star Schema)

The Power BI visualization layer connects directly to the processed summary tables generated by the project pipeline in the `powerbi_exports/` directory.

### Table Schema & Roles:

| Table Name | Role | Primary Key / Grain | Description |
| :--- | :--- | :--- | :--- |
| `daily_summary` | Fact Table | `Date` (Daily) | Daily mean active power, max power, voltage, intensity, sub-meterings |
| `hourly_summary` | Fact Table | `Datetime` (Hourly) | 34,589 hourly aggregated readings with mean, min, max power |
| `hour_of_day_summary` | Dimension | `Hour` (0 - 23) | Diurnal profile, hourly mean, median, peak active power |
| `weekday_summary` | Dimension | `Weekday` (Mon - Sun) | Day of week aggregation, day type (Weekday vs. Weekend) |
| `submeter_summary` | Dimension | `Sub_meter` (1, 2, 3) | Average energy allocations for kitchen, laundry, and climate control |
| `quality_and_test_summary` | Context Table | `Metric` | Clean row counts, missing cell treatments, Welch's t-test p-value |
| `regression_model_comparison` | Fact / Benchmark | `Model` | Evaluation metrics: Test MAE (kW), RMSE (kW), and $R^2$ scores |
| `regression_test_predictions` | Fact Table | `Datetime` (Test Period) | Actual vs. predicted hourly active power for ML models |

## 2. Power BI Data Ingestion Options

You can load data into Power BI through **two different methods**:

### Option A: Direct CSV Ingestion (Recommended & Fastest)
1. Open **Power BI Desktop**.
2. Click **Get Data** ➔ **Folder** (or **Text/CSV**).
3. Browse to `powerbi_exports/` and select all 9 CSV files.
4. Click **Load**.
5. Set `Date` and `Datetime` fields as **Date/Time** data types in Power Query.

### Option B: Live REST API Connector (Full-Stack Bonus)
Power BI can pull live JSON data from the running Flask API (`python app.py`):
1. In Power BI, click **Get Data** ➔ **Web**.
2. Select **Advanced** and enter the API URL:
   - `http://127.0.0.1:5000/api/daily`
   - `http://127.0.0.1:5000/api/hour-of-day`
   - `http://127.0.0.1:5000/api/weekday`
   - `http://127.0.0.1:5000/api/regression-comparison`
3. In Power Query, convert the JSON record list to a table:
   ```powerquery
   let
       Source = Json.Document(Web.Contents("http://127.0.0.1:5000/api/daily")),
       Table = Table.FromList(Source, Splitter.SplitByNothing(), null, null, ExtraValues.Error),
       Expanded = Table.ExpandRecordColumn(Table, "Column1", {"Date", "Mean_Active_Power_kW", "Max_Active_Power_kW", "Mean_Voltage_V", "Sub_metering_1", "Sub_metering_2", "Sub_metering_3"})
   in
       Expanded
   ```

## 3. Ready-to-Use DAX Measures

Create a new calculated table `_Measures` in Power BI and paste the following DAX formulas:

### KPI & Consumption Metrics:
```dax
// 1. Average Global Active Power
Avg_Active_Power_kW = 
AVERAGE('hourly_summary'[Mean_Active_Power_kW])

// 2. Peak Active Power Recorded
Peak_Active_Power_kW = 
MAX('hourly_summary'[Max_Active_Power_kW])

// 3. Estimated Total Energy (kWh)
Total_Energy_kWh = 
SUM('hourly_summary'[Mean_Active_Power_kW])

// 4. Weekend Average Power
Weekend_Avg_Power = 
CALCULATE(
    AVERAGE('hourly_summary'[Mean_Active_Power_kW]),
    'weekday_summary'[Day_Type] = "Weekend"
)

// 5. Weekday Average Power
Weekday_Avg_Power = 
CALCULATE(
    AVERAGE('hourly_summary'[Mean_Active_Power_kW]),
    'weekday_summary'[Day_Type] = "Weekday"
)

// 6. Weekend vs Weekday Percentage Delta
Weekend_Weekday_Variance_% = 
DIVIDE([Weekend_Avg_Power] - [Weekday_Avg_Power], [Weekday_Avg_Power], 0) * 100
```

### Machine Learning Forecasting Evaluation Measures:
```dax
// 7. Test Set Mean Absolute Error (MAE)
Forecast_MAE_kW = 
AVERAGEX(
    'regression_test_predictions',
    ABS('regression_test_predictions'[Actual_kW] - 'regression_test_predictions'[Random_Forest_Predicted_kW])
)

// 8. Test Set Root Mean Squared Error (RMSE)
Forecast_RMSE_kW = 
SQRT(
    AVERAGEX(
        'regression_test_predictions',
        ('regression_test_predictions'[Actual_kW] - 'regression_test_predictions'[Random_Forest_Predicted_kW]) ^ 2
    )
)
```

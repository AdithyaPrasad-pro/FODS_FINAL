## 1. Power BI Architecture & Data Model (Star Schema)

The Power BI visualization layer connects directly to the processed summary tables generated by the project pipeline in the `powerbi_exports/` directory.

### Table Schema & Roles:

| Table Name | Role | Primary Key / Grain | Description |
| :--- | :--- | :--- | :--- |
| `daily_summary` | Fact Table | `Date` (Daily) | Daily mean active power, max power, voltage, intensity, sub-meterings |
| `hourly_summary` | Fact Table | `Datetime` (Hourly) | 34,589 hourly aggregated readings with mean, min, max power |
| `recommendation_classes` | Dimension | `Consumption_Class` | The 3 WattWise tiers: Low, Normal, High with threshold cutoffs and recommendations |
| `hour_of_day_summary` | Dimension | `Hour` (0 - 23) | Diurnal profile, hourly mean, median, peak active power (8:00 PM peak) |
| `weekday_summary` | Dimension | `Weekday` (Mon - Sun) | Day of week aggregation, day type (Weekday vs. Weekend) |
| `submeter_summary` | Dimension | `Sub_meter` (1, 2, 3) | Average energy allocations for kitchen, laundry, and climate control |
| `quality_and_test_summary` | Context Table | `Metric` | Clean row counts (2,075,259), missing cell treatments, Welch's t-test p-value |

## 2. Power BI Data Ingestion

1. Open **Power BI Desktop**.
2. Click **Get Data** ➔ **Text/CSV**.
3. Browse to `powerbi_exports/` and select the tables:
   - `hour_of_day_summary.csv`
   - `weekday_summary.csv`
   - `submeter_summary.csv`
   - `quality_and_test_summary.csv`
   - `recommendation_classes.csv`
4. Click **Load**.

## 3. Recommended DAX Measures

```dax
// 1. Average Global Active Power
Avg_Active_Power_kW = 
AVERAGE('hour_of_day_summary'[Mean_Active_Power_kW])

// 2. Peak Active Power Recorded
Peak_Active_Power_kW = 
MAX('hour_of_day_summary'[Peak_Active_Power_kW])

// 3. Weekend vs Weekday Percentage Surge
Weekend_Surge_% = 
VAR WeekdayAvg = CALCULATE(AVERAGE('weekday_summary'[Mean_Active_Power_kW]), 'weekday_summary'[Day_Type] = "Weekday")
VAR WeekendAvg = CALCULATE(AVERAGE('weekday_summary'[Mean_Active_Power_kW]), 'weekday_summary'[Day_Type] = "Weekend")
RETURN DIVIDE(WeekendAvg - WeekdayAvg, WeekdayAvg, 0) * 100
```
